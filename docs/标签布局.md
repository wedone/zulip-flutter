```
┌────── 左栏：数字+运算符 ───────┐  ┌────── 右栏：数学常用大写字母 ──────┐
│  0    1    2    3    │  A    B    C    D   │
│  4    5    6    7    │  E    F    G    H   │
│  8    9    .    ,    │  I    J    K    L   │
│  +    −    ×    ÷    │  M    N    O    P   │
│  =    √    ⋅    |    │  Q    R    S    T   │
│  /    ≠    (    )    │  U    V    W    X   │
│  [    ]    {    }    │  Y    Z    α    β   │
│  ≤    ≥    <    >    │  γ    θ    λ    π   │
│  _    ^    sin  cos  │  Δ    Σ    Ω    ∞   │
└──────────────────────┘  └────────────────────┘
```

**说明**：
- **左栏**：完整数字键盘(0-9) + 小数点/逗号 + 基础运算符(+−×÷=) + 根号/点乘/绝对值 + 除法/不等号 + 括号([]{}()) + 上下标符号 + 常用函数(sin/cos)
- **右栏**：26个大写英文字母 + 高频希腊字母(αβγθλπΔΣΩ) + ∞
- 字母按字母顺序排列，`α β γ θ λ π Δ Σ Ω` 因使用频率高混入右栏
- 9 行布局，左栏 34 符号，右栏 35 符号，一屏展示，不用翻页

### 标签5：模板

```
a/b   √□   ⁿ√□   xₙᵐ
∑ⁿᵢ₌₁  ∫ᵃᵇ  lim→∞  矩阵
分段   logₐb  {…}   align
C(n,k)  $…$   $$\n…\n$$
```

**说明**：
- `a/b`：分数 `\frac{□}{□}`，光标定位到分子
- `√□`：根号 `\sqrt{□}`，光标定位到根号内
- `ⁿ√□`：n 次根号 `\sqrt[n]{□}`，光标定位到根指数
- `xₙᵐ`：上下标 `_{□}^{□}`，光标定位到下标
- `∑ⁿᵢ₌₁`：求和 `\sum_{i=1}^{n}`
- `∫ᵃᵇ`：定积分 `\int_{a}^{b}`
- `lim→∞`：极限 `\lim_{x \to \infty}`
- `矩阵`：矩阵环境 `\begin{pmatrix}□\end{pmatrix}`，光标定位到内部
- `分段`：分段函数 `\begin{cases}□\end{cases}`，光标定位到内部
- `logₐb`：对数 `\log_{□}{□}`，光标定位到底数
- `{…}`：大括号包裹 `\{□\}`
- `align`：多行对齐公式 `\begin{align}□\end{align}`，光标定位到内部
- `C(n,k)`：组合数 `\binom{□}{□}`，光标定位到分子
- `$…$`：行内公式包裹，光标定位到中间
- `$$\n…\n$$`：独立公式包裹（换行格式），发送时自动转换为 ` ```math ` 代码块

## 🔑 关键设计点

### 1. 数字键盘的必要性
- 有了 `0-9` 和 `.` `,`，用户输入 `f(x) = 2x + 3.14` 完全不需要切回系统键盘
- 括号 `( ) [ ] { }` 也是数学输入高频需求

### 2. 右栏为什么混入希腊字母
- 高中数学中，`α β γ θ λ π Δ Σ Ω` 的使用频率不亚于英文字母
- 与其单独开一个标签，不如放在"常用"右栏，减少切换

### 3. 左右分栏布局
- "常用"标签采用左右分栏，各 4 列（共 8 列）
- 每行 8 个按钮，按钮尺寸 44×44，总宽度约 352px
- 手机屏幕 375px 刚好够用

### 4. 标签6（最近）
- 原来没有"最近"标签，单独开一个标签存放最近使用的符号
- 显示 20 个，持久化存储 20 个

### 5. 6 个标签分类
- 常用、关系、函数、希腊、模板、最近
- 所有标签名称限制 2 个字，避免拥挤
