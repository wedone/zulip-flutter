**说明**：

- **右栏**：26个大写英文字母（完整版）+ 高频希腊字母
- 字母按字母顺序排列，`α β γ θ λ π Δ Σ Ω` 因使用频率高混入右栏
- 7 行布局，左栏 30 符号，右栏 34 符号，一屏展示，不用翻页

## 🔑 关键设计点

### 1. 数字键盘的必要性
- 有了 `0-9` 和 `.` `,`，用户输入 `f(x) = 2x + 3.14` 完全不需要切回系统键盘
- 括号 `( ) [ ] { }` 也是数学输入高频需求

### 2. 右栏为什么混入希腊字母
- 高中数学中，`α β γ θ λ π Δ Σ Ω` 的使用频率不亚于英文字母
- 与其单独开一个标签，不如放在"常用"右栏，减少切换

### 3. 按钮尺寸问题
- 当前按钮 44×44，8 列 = 352px，手机屏幕 375px 刚好够
- 但 8 行内容较多，可能需要工具栏高度从 220px 调整到 300px 左右
- 或者考虑左右分栏各 4 列，但内容分两页（上/下滑动）
