## 常用标签
 ```
┌──────  左栏  ──────┐    ┌──────  右栏  ──────┐
│  0   1   2   3    │    │  A   B   C   D    │
│  4   5   6   7    │    │  E   F   G   H    │
│  8   9   .   =    │    │  I   J   K   L    │
│  +   −   ×   /    │    │  M   N   O   P    │
│  √   ⋅   ,   $$   │    │  Q   R   S   T    │
│  ()  []  {}  ||   │    │  U   V   W   X    │
│  <   >   _   ^    │    │  Y   Z   α   β    │
│  ²   ³  a/b  xₙᵐ  │    │  γ   θ   λ   π    │
│  √□ ⁿ√□ 向量       │    │  Δ   Σ   Ω   ∞    │
└───────────────────┘    └───────────────────┘
```
1.成对（“$$”“||”也算）的符号输入后光标在中间
2.向量用 “\vec”
3.a/b  xₙᵐ √□ ⁿ√□ 向量 是输入模版
