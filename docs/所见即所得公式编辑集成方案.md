# 所见即所得（WYSIWYG）公式编辑集成方案

## 1. 背景与问题

### 1.1 当前状态

zulip-flutter 是一个 Zulip 即时通讯客户端，支持在消息中发送 LaTeX 数学公式。当前已有的数学相关功能：

- **数学键盘工具栏**（自定义扩展）：Flutter 原生的分类键盘（常用、关系与集合、函数、希腊字母、公式模板、最近），用于向输入框插入 Unicode 符号和 LaTeX 代码片段。该功能是对上游 zulip-flutter 的 fork 修改——**上游官方版本仅使用系统键盘**，没有数学键盘工具栏
- **LaTeX 预览**：使用 `flutter_math_fork` 渲染输入框中的 LaTeX 代码为可视化公式
- **消息发送**：发送时通过 `convertLatexDelimitersToZulip()` 转换界定符（如 `\(...\)` → `$$...$$`）

> ⚠️ 注意：数学键盘工具栏是 fork 新增功能，非上游官方特性。本次改造可能将其完全移除。

### 1.2 核心问题

现有的「数学键盘 → 插入 LaTeX 代码 → 预览渲染」模式存在以下不足：

- 用户输入公式时**看不到实时渲染效果**，只能看到 LaTeX 代码
- 数学结构（分式、根式、矩阵等）的嵌套需要手动输入 `\frac{}{}` 等代码，不够直观
- 学习门槛较高，不熟悉 LaTeX 语法的用户难以使用

### 1.3 目标

在 zulip-flutter 中引入**所见即所得（WYSIWYG）公式编辑**功能，让用户：

- 在可视化界面中直接编辑数学公式，**编辑即预览**
- 编辑完成后自动生成 LaTeX 代码，插入到输入框的光标位置
- 与现有的中文/普通文本输入流程无缝配合

### 1.4 终极目标

**用 `flutter_mathlive_mixed` 内置的虚拟键盘（`<math-virtual-keyboard>`）替换 fork 自定义的数学键盘工具栏。**

- 如果 MathLive 虚拟键盘的功能和体验足够优秀（符号覆盖度、分类布局、响应速度），则完全移除现有的数学键盘工具栏
- 如果 MathLive 虚拟键盘在某些方面（如常用符号快速输入）不够便捷，则保留一个极简的符号快速插入栏（仅 1 行，仅最常用符号）
- 最终减少维护量：不再需要维护一套独立的 Flutter 原生数学键盘

## 2. 核心约束（不可变更）

以下约束是 zulip-flutter 与 Zulip 服务器通信的硬性要求，任何方案必须遵守：

1. **输入框内容必须是纯文本**。zulip-flutter 的 `TextField` 中存储的是混合了中文和 LaTeX 语法文本的字符串，例如：`圆的面积是 \(A = \pi r^2\)`
2. **发送到服务器的也是纯文本**。最终提交给 Zulip 服务器的消息内容是纯文本格式，LaTeX 公式以特定界定符包裹
3. **不需要替换 TextField**。WYSIWYG 编辑的结果（LaTeX 代码）以文本形式插入到现有 TextField 的光标位置
4. **渲染使用 flutter_math_fork**。消息历史、预览区域等展示渲染仍使用 `flutter_math_fork`，不做替换

### 详细步骤

1. **输入普通文本**：使用系统键盘在 TextField 中输入中文、英文等普通文本
2. **光标定位**：将光标移动到需要插入公式的位置（或选中要替换的文本）
3. **打开可视编辑器**：点击「📐 可视公式」按钮，弹出 `MathLiveEditorPage`
4. **WYSIWYG 编辑**：在 `<math-field>` 中可视化编辑公式，虚拟键盘替代系统键盘
5. **确认插入**：点击「Insert」，编辑器返回 LaTeX 代码（如 `A = \pi r^2`）
6. **插入 TextField**：将 LaTeX 代码（含界定符 `\(` 和 `\)`）插入到第 2 步的光标位置
7. **重复**：继续输入文本或插入更多公式，最终发送完整消息

## 4. 技术方案

### 4.1 核心技术选型

| 组件 | 技术 | 用途 |
|------|------|------|
| WYSIWYG 编辑器 | **MathLive** (via `flutter_mathlive_mixed`) | 可视化公式编辑 |
| 虚拟键盘 | **MathLive virtual-keyboard** (内嵌于 WebView) | 公式编辑时的数学输入 |
| LaTeX 渲染展示 | **flutter_math_fork** (已有) | 预览区域、消息历史渲染 |
| 文本输入 | **Flutter TextField** (已有) | 普通文本 + LaTeX 文本 |
| WebView | **webview_flutter** (flutter_mathlive_mixed 依赖) | 承载 MathLive 编辑环境 |

### 4.2 WYSIWYG 编辑器启动方式

使用 `flutter_mathlive_mixed` 包提供的 `MathLiveEditorPage.open()` 以**全屏弹窗**方式打开。

```dart
final String? latex = await MathLiveEditorPage.open(
  context,
  isDark: isDark,
  initialLatex: selectedText, // 可选：传入选中文本
  theme: MathLiveMixedTheme.defaults,
);
```

- **全屏弹窗**：提供完整的编辑区域和虚拟键盘空间
- 不采用内嵌模式（`MathLiveEmbeddedEditor`），避免 compose box 布局复杂化
- 弹窗结束后返回 LaTeX 文本（或 `null` 表示取消）

### 4.3 LaTeX 插入逻辑

```dart
/// 在 TextField 光标位置插入带界定符的 LaTeX
void _insertLatexAtCursor(String latex) {
  final text = controller.content.text;
  final selection = controller.content.selection;

  // 如果选中的文本本身就是 LaTeX（被 \(...\) 包裹），则替换内容
  // 否则插入新的带界定符的公式
  final String wrapped;
  if (latex.contains(r'\( ') || latex.contains(r'\(\)')) {
    wrapped = latex; // 已含界定符
  } else {
    wrapped = r'\( $latex\)';
  }

  final newText = text.replaceRange(selection.start, selection.end, wrapped);
  final cursorPos = selection.start + wrapped.length;

  controller.content.value = TextEditingValue(
    text: newText,
    selection: TextSelection.collapsed(offset: cursorPos),
  );
}
```

### 4.4 LaTeX 界定符

| 场景 | 界定符 | 示例 |
|------|--------|------|
| 输入框内 | `\(...\)` | `\(A = \pi r^2\)` |
| 发送到服务器 | `$$...$$` | `$$A = \pi r^2$$` |
| 转换时机 | 发送前 `convertLatexDelimitersToZulip()` | 已有逻辑，无需修改 |

## 5. 性能优化（关键）

### 5.1 优化 ①：本地打包 MathLive 资源

**问题**：当前 `flutter_mathlive_mixed` 从 CDN 加载 MathLive JS/CSS：

```html
<!-- mathlive_editor.html -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/mathlive@0.101.2/dist/mathlive-static.css" />
<script src="https://cdn.jsdelivr.net/npm/mathlive@0.101.2/dist/mathlive.min.js"></script>
```

国内访问 CDN 可能不稳定，且增加加载延迟。

**方案**：

1. 下载 `mathlive.min.js` 和 `mathlive-static.css` 放入 `assets/mathlive/`
2. 修改 `mathlive_editor.html` 为本地引用：
   ```html
   <link rel="stylesheet" href="mathlive-static.css" />
   <script src="mathlive.min.js"></script>
   ```
3. 修改 Dart 加载代码，`baseUrl` 使用本地文件协议或移除

### 5.2 优化 ②：版本升级（安全修复）

将 MathLive 从 `0.101.2`（2024-06）升级到 `0.110.0`（2026-06）。

关键原因：**XSS 安全修复**——`\text{}` 内容未转义直接渲染到 DOM 的问题。

升级方式：替换 `mathlive.min.js` 和 `mathlive-static.css` 文件，API 兼容。

### 5.3 优化 ③：WebView 预加载（建议第二阶段实施）

在 ComposeBox 初始化时，后台**预先创建并初始化**一个隐藏的 WebView 实例：

```dart
// ComposeBox 初始化时
late Future<void> _mathEditorPreload;

@override
void initState() {
  super.initState();
  // 后台预加载 MathLive WebView
  _mathEditorPreload = _preloadMathWebView();
}

Future<void> _preloadMathWebView() async {
  // 创建隐藏 WebView，加载 MathLive
  // 加载完成即就绪
}
```

用户点击「📐 可视公式」时，直接复用预加载的 WebView，**用户感知为秒开**。

| 阶段 | 操作 | 延迟 | 用户感知 |
|------|------|------|---------|
| 当前（CDN + 首次加载） | 下载 JS → 初始化 WebView → 渲染 | 500~2000ms | 明显的 loading |
| 优化后（本地 + 预加载） | 从内存读取 → 直接显示 | ~0ms（预加载） | **秒开** |

## 6. 现有数学键盘的处理（关键决策）

### 6.1 背景

现有数学键盘工具栏是对上游 zulip-flutter 的 fork 新增功能，不是官方特性。它包含了 6 个分类、长按变体、最近使用等功能，维护成本较高。

### 6.2 终极目标

**用 `flutter_mathlive_mixed` 内置的 `<math-virtual-keyboard>` 完全替换现有的数学键盘工具栏。**

当用户打开 `MathLiveEditorPage` 全屏弹窗后，输入数学公式完全在 `<math-field>` + `<math-virtual-keyboard>` 中完成，不再需要外部的数学键盘工具栏。MathLive 虚拟键盘的定制改造（如调整按键分类、布局等）在可接受范围内均可进行。

无需保留极简符号栏作为兜底——单一公式输入也通过打开编辑器完成，简化整体架构。

### 6.3 现有键盘功能对照

| 功能 | 现有数学键盘 | MathLive virtual keyboard | 是否需要 |
|------|-------------|--------------------------|---------|
| 符号分类标签（常用/关系/函数/希腊/模板） | 6 分类 | 内置分类 + 可定制 | ✅ |
| 长按变体（如长按 α 出 β γ） | 有 | 内置 variant panel | ✅ |
| 最近使用标签 | 有 | 无 | ❌ 不需要 |
| 快捷键/快捷输入 | 部分 | 内置 LaTeX 自动补全 | ✅ |
| 自定义符号布局 | 完全定制 | 可通过 keyboard layout API 定制 | ✅（按需） |

### 6.4 「📐 可视公式」按钮位置

不管是否保留极简符号栏，**「📐 可视公式」按钮始终存在**，置于 compose_box 的输入工具栏中。用户每次需要输入公式时，流程都是：

```
光标定位 → 点击 📐 → MathLiveEditorPage 弹窗 → WYSIWYG 编辑 → Insert → LaTeX 插入 TextField
```

### 6.5 旧数学键盘代码的清理

**直接完全移除**，需要删除的内容：

- `lib/widgets/math_keyboard/` 目录下所有文件
- `compose_box.dart` 中与 `mathKeyboardToolbarVisible` 相关的状态和逻辑
- `keyboard: _mathKeyboardToolbarVisible` 相关配置
