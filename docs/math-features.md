# 数学输入增强功能

## 用户需求

Zulip 客户端的主要用户群体是高中生，他们在聊天中经常需要输入数学算式。系统键盘输入希腊字母（αβγδ）、运算符号（±×÷√∑∫）、关系符号（≠≤≥∥⊥∠）、集合符号（∈⊆∪∩∅）等非常麻烦，严重影响数学交流效率。

此外，Zulip 对 LaTeX 数学公式的界定符有非标准要求（使用 `$$...$$` 表示行内公式，` ```math...``` ` 表示独立公式），与通用 LaTeX 习惯（`$...$`、`$$...$$`）不同，容易导致用户输入的公式无法正确渲染。

用户在输入公式时无法预览渲染效果，发送后绑定 AI Bot 会立即触发 AI 工作，增加了试错成本。

## 方案概述

本方案包含三个核心功能：

1. **LaTeX 界定符自动转换** — 发送消息时自动将通用 LaTeX 界定符转换为 Zulip 格式
2. **数学符号工具栏** — 提供分类符号面板，支持快速输入数学符号和公式模板
3. **LaTeX 实时预览** — 输入框内检测到成对界定符时自动渲染公式预览

## 一、LaTeX 界定符自动转换

### 1.1 功能描述

在用户发送新消息时，自动将通用 LaTeX 界定符转换为 Zulip 特定格式。编辑已有消息时不进行转换。

### 1.2 转换规则

| 输入 | 输出 | 说明 |
|------|------|------|
| `$...$` | `$$...$$` | 通用行内公式 → Zulip 行内公式 |
| `\(...\)` | `$$...$$` | LaTeX 行内公式 → Zulip 行内公式 |
| `$$...$$`（含换行） | `` ```math\n...\n``` `` | 通用独立公式 → Zulip 独立公式 |
| `\[...\]` | `` ```math\n...\n``` `` | LaTeX 独立公式 → Zulip 独立公式 |
| `$$...$$`（无换行） | 不转换 | 已符合 Zulip 行内格式 |

### 1.3 保护规则

以下区域内的内容不会被转换：

- **代码块**（` ```...``` `）— 包括带语言提示的代码块
- **行内代码**（` `...` `）
- **已有 `` ```math `` 块** — 避免重复转换
- **转义美元符号**（`\$`）— 不作为界定符处理

### 1.4 转换顺序

规则按以下顺序应用，确保不产生冲突：

1. 保护特殊区域（代码块、行内代码、已有 math 块、`\$`）
2. `\[...\]` → `` ```math\n...\n``` ``
3. 保护步骤 2 产生的新 `` ```math `` 块
4. `$$...$$`（含换行）→ `` ```math\n...\n``` ``
5. 保护步骤 4 产生的新 `` ```math `` 块
6. `\(...\)` → `$$...$$`
7. `$...$` → `$$...$$`
8. 恢复保护区域

先处理独立公式（display math），再处理行内公式（inline math），避免 `$$...$$` 被规则 4 产生后又被规则 2 误处理。

### 1.5 设置开关

- 路径：设置 > 实验性功能 > 自动转换 LaTeX 界定符
- 默认值：开启
- 实现：`BoolGlobalSetting.autoConvertLatexDelimiters`

### 1.6 代码位置

| 文件 | 说明 |
|------|------|
| `lib/model/latex_converter.dart` | 核心转换逻辑 |
| `lib/model/settings.dart` | 设置项定义 |
| `lib/widgets/compose_box.dart` | 发送时调用转换 |
| `test/model/latex_converter_test.dart` | 单元测试 |

## 二、数学符号工具栏

### 2.1 功能描述

在消息输入框上方展开数学符号面板，用户可以快速点选符号插入到光标位置。工具栏展开后保持打开状态，需手动关闭。

### 2.2 符号分类与布局

工具栏包含 6 个分类标签页：

#### 标签1：常用（左右分栏，各 4 列）

```
┌────── 左栏：数字+运算符 ───────┐  ┌────── 右栏：数学常用大写字母 ──────┐
│  0    1    2    3    │  A    B    C    D   │
│  4    5    6    7    │  E    F    G    H   │
│  8    9    .    ,    │  I    J    K    L   │
│  +    −    ×    ÷    │  M    N    O    P   │
│  =    √    ⋅    |    │  Q    R    S    T   │
│  /    ≠    (    )    │  U    V    W    X   │
│  [    ]    {    }    │  Y    Z    α    β   │
│  ≤    ≥    <    >    │  γ    θ    λ    π   │
│  _    ^    sin  cos  │  Δ    Σ    Ω    ∞   │
└──────────────────────┘  └────────────────────┘
```

- **左栏**：完整数字键盘(0-9) + 小数点/逗号 + 基础运算符(+−×÷=) + 根号/点乘/绝对值 + 除法/不等号 + 括号 + 上下标符号 + 常用函数(sin/cos)
- **右栏**：26个大写英文字母 + 高频希腊字母(αβγθλπΔΣΩ) + ∞
- 9 行布局，左栏 34 符号，右栏 35 符号，一屏展示，不用翻页

#### 标签2：关系与集合

```
=    ≠    ≡    ≈    ≅    ∝
<    >    ≤    ≥    ≪    ≫
∥    ⊥    ∠    △    ∼    ±
∈    ∉    ⊆    ⊇    ⊂    ⊃
∪    ∩    ∖    ∅
∀    ∃    ⇒    ⇔    ∧    ∨
→    ←    ↑    ↓
```

- 关系符 + 集合 + 逻辑符号 + 箭头合并
- 高中数学"常用逻辑用语"章节全覆盖

#### 标签3：函数

```
sin   cos   tan   cot   sec   csc
arcsin arccos arctan
log   ln    lg    lim   max   min
∫    ∬    ∮    ∑    ∏    ∂    ∇
```

- 所有三角函数、对数函数、极限
- 微积分符号

#### 标签4：希腊字母（完整版，分小写/大写两区）

```
小写：α   β   γ   δ   ε   ζ   η   θ
      ι   κ   λ   μ   ν   ξ   π   ρ
      σ   τ   υ   φ   χ   ψ   ω
大写：Α   Β   Γ   Δ   Ε   Ζ   Η   Θ
      Ι   Κ   Λ   Μ   Ν   Ξ   Ο   Π
      Ρ   Σ   Τ   Υ   Φ   Χ   Ψ   Ω
```

#### 标签5：模板

```
a/b   √□   ⁿ√□   xₙᵐ
∑ⁿᵢ₌₁  ∫ᵃᵇ  lim→∞  矩阵
分段   logₐb  {…}   align
C(n,k)  $…$   $$\n…\n$$
```

**模板说明**：
- `a/b`：分数 `\frac{□}{□}`，光标定位到分子
- `√□`：根号 `\sqrt{□}`，光标定位到根号内
- `ⁿ√□`：n 次根号 `\sqrt[n]{□}`，光标定位到根指数
- `xₙᵐ`：上下标 `_{□}^{□}`，光标定位到下标
- `∑ⁿᵢ₌₁`：求和 `\sum_{i=1}^{n}`
- `∫ᵃᵇ`：定积分 `\int_{a}^{b}`
- `lim→∞`：极限 `\lim_{x \to \infty}`
- `矩阵`：矩阵环境 `\begin{pmatrix}□\end{pmatrix}`
- `分段`：分段函数 `\begin{cases}□\end{cases}`
- `logₐb`：对数 `\log_{□}{□}`
- `{…}`：大括号包裹 `\{□\}`
- `align`：多行对齐公式 `\begin{align}□\end{align}`
- `C(n,k)`：组合数 `\binom{□}{□}`
- `$…$`：行内公式包裹，发送时转换为 `$$...$$`
- `$$\n…\n$$`：独立公式包裹（换行格式），发送时转换为 ` ```math ` 代码块

#### 标签6：最近

- 显示最近使用的 20 个符号
- 持久化存储，跨会话保留
- 去重记录，最近使用的排在最前面

### 2.3 符号类型

| 类型 | 说明 | 示例 |

| `LatexWrapper` | 包裹选中文字，无选中时插入前后缀并将光标置于中间 | `$...$`, `$$...$$` |

### 2.4 交互行为

- 点击输入框旁的 Σ 按钮展开/关闭工具栏
- 工具栏展开后点选符号，符号插入到光标位置，工具栏保持打开
- LaTeX 模板插入后光标自动定位到待填位置
- 选中文字后点击包裹类符号，文字被前后缀包裹

## 三、LaTeX 实时预览

### 3.1 功能描述

在输入框中输入公式时，自动检测到成对的 LaTeX 界定符并渲染公式预览。预览区域出现在输入框和按钮行之间，帮助用户在发送前确认公式是否正确渲染。

### 3.2 触发条件

预览区域仅在**同时满足**以下条件时显示：

1. 输入框有焦点
2. 光标所在位置的前后存在一对成对的界定符
3. 界定符类型匹配：`$...$`、`$$...$$`、`\(...\)`、`\[...\]`

不满足任一条件时，预览区域不显示，避免无效渲染。

### 3.3 检测规则

| 界定符 | 预览模式 | 说明 |
|--------|---------|------|
| `$...$` | 行内 | 内容不含 `$` 和换行 |
| `$$...$$`（无换行） | 行内 | 作为行内公式预览 |
| `$$...$$`（含换行） | 独立 | 作为独立公式预览 |
| `\(...\)` | 行内 | LaTeX 行内 |
| `\[...\]` | 独立 | LaTeX 独立 |

- **边界条件**：光标必须在定界符严格内部，在定界符位置时不触发预览
- **转义处理**：`\$` 不作为界定符
- **多公式**：只预览光标所在的那个公式
- **失焦行为**：输入框失去焦点时预览区域消失

### 3.4 性能优化

- 300ms 防抖：避免打字过程中频繁重渲染
- 失焦自动隐藏：不保留预览状态，零渲染开销

### 3.5 代码位置

| 文件 | 说明 |
|------|------|
| `lib/model/latex_preview.dart` | 界定符检测逻辑 |
| `lib/widgets/latex_preview.dart` | 预览区域 Widget |
| `test/model/latex_preview_test.dart` | 单元测试 |

## 四、技术实现细节

### 4.1 LaTeX 转换的保护机制

转换过程使用"保护-转换-恢复"模式：

1. **保护阶段**: 将不应转换的区域替换为占位符（`\x00PROTECTED_N\x00`）
2. **转换阶段**: 在剩余文本上应用转换规则，每步转换后保护新产生的 `` ```math `` 块
3. **恢复阶段**: 按逆序将占位符还原为原始内容

### 4.2 工具栏状态管理

工具栏的显示/隐藏状态由 `ComposeBoxState` 管理：

- `_mathSymbolsToolbarVisible` 状态变量控制工具栏可见性
- `_toggleMathSymbolsToolbar()` 方法切换状态
- 切换窄话题（narrow）时重置工具栏状态为隐藏

### 4.3 发送流程

```
用户点击发送
  → 获取消息内容（textNormalized）
  → 检查设置开关是否开启
  → 如果开启，调用 convertLatexDelimitersToZulip()
  → 发送转换后的内容
```

编辑消息时走不同的保存路径，不经过转换逻辑。

### 4.4 预览流程

```
用户输入文字
  → 光标位置变化触发检测
  → 300ms 防抖延迟
  → findLatexAtCursor() 查找光标所在公式
  → 找到公式 → 显示预览区域，使用 flutter_math_fork 渲染
  → 未找到公式 → 隐藏预览区域
```
