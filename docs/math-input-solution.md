# 数学输入方案

## 背景

Zulip 客户端的主要用户群体是高中生，他们在聊天中经常需要输入数学算式。系统键盘输入希腊字母（αβγδ）、运算符号（±×÷√∑∫）、关系符号（≠≤≥∥⊥∠）、集合符号（∈⊆∪∩∅）等非常麻烦，严重影响数学交流效率。

此外，Zulip 对 LaTeX 数学公式的界定符有非标准要求（使用 `$$...$$` 表示行内公式，`` ```math...``` `` 表示独立公式），与通用 LaTeX 习惯（`$...$`、`$$...$$`）不同，容易导致用户输入的公式无法正确渲染。

## 方案概述

本方案包含两个核心功能：

1. **LaTeX 界定符自动转换** — 发送消息时自动将通用 LaTeX 界定符转换为 Zulip 格式
2. **数学符号工具栏** — 提供分类符号面板，支持快速输入数学符号和公式模板

## 一、LaTeX 界定符自动转换

### 1.1 功能描述

在用户发送新消息时，自动将通用 LaTeX 界定符转换为 Zulip 特定格式。编辑已有消息时不进行转换。

### 1.2 转换规则

| 输入 | 输出 | 说明 |
|------|------|------|
| `$...$` | `$$...$$` | 通用行内公式 → Zulip 行内公式 |
| `\(...\)` | `$$...$$` | LaTeX 行内公式 → Zulip 行内公式 |
| `$$...$$`（含换行） | `` ```math\n...\n``` `` | 通用独立公式 → Zulip 独立公式 |
| `\[...\]` | `` ```math\n...\n``` `` | LaTeX 独立公式 → Zulip 独立公式 |
| `$$...$$`（无换行） | 不转换 | 已符合 Zulip 行内格式 |

### 1.3 保护规则

以下区域内的内容不会被转换：

- **代码块**（` ```...``` `）— 包括带语言提示的代码块
- **行内代码**（`` `...` ``）
- **已有 `` ```math `` 块** — 避免重复转换
- **转义美元符号**（`\$`）— 不作为界定符处理

### 1.4 转换顺序

规则按以下顺序应用，确保不产生冲突：

1. 保护特殊区域（代码块、行内代码、已有 math 块、`\$`）
2. `\[...\]` → `` ```math\n...\n``` ``
3. 保护步骤 2 产生的新 `` ```math `` 块
4. `$$...$$`（含换行）→ `` ```math\n...\n``` ``
5. 保护步骤 4 产生的新 `` ```math `` 块
6. `\(...\)` → `$$...$$`
7. `$...$` → `$$...$$`
8. 恢复保护区域

先处理独立公式（display math），再处理行内公式（inline math），避免 `$$...$$` 被规则 4 产生后又被规则 2 误处理。

### 1.5 设置开关

- 路径：设置 > 实验性功能 > 自动转换 LaTeX 界定符
- 默认值：开启
- 实现：`BoolGlobalSetting.autoConvertLatexDelimiters`

### 1.6 代码位置

| 文件 | 说明 |
|------|------|
| `lib/model/latex_converter.dart` | 核心转换逻辑 |
| `lib/model/settings.dart` | 设置项定义 |
| `lib/widgets/compose_box.dart` | 发送时调用转换 |
| `test/model/latex_converter_test.dart` | 单元测试 |

## 二、数学符号工具栏

### 2.1 功能描述

在消息输入框上方展开数学符号面板，用户可以快速点选符号插入到光标位置。工具栏展开后保持打开状态，需手动关闭。

### 2.2 符号分类

工具栏包含 6 个分类标签：

#### 常用
- **函数**: sin, cos, tan, cot, sec, csc, arcsin, arccos, arctan, log, ln, lg, lim, max, min, sup, inf, arg
- **常用符号**: ±, ×, ÷, √, ∞, ∠, °, ≠, ≤, ≥, ∈
- **LaTeX 模板**: `\frac{}{}`, `\sqrt{}`, `^{}`, `_{} `

#### 希腊字母
- **小写**: α, β, γ, δ, ε, ζ, η, θ, ι, κ, λ, μ, ν, ξ, π, ρ, σ, τ, υ, φ, χ, ψ, ω
- **大写**: Α, Β, Γ, Δ, Ε, Ζ, Η, Θ, Ι, Κ, Λ, Μ, Ν, Ξ, Ο, Π, Ρ, Σ, Τ, Υ, Φ, Χ, Ψ, Ω

#### 运算符
±, ×, ÷, ∘, ⊙, ⊗, ⊕, ∂, ∇, ∫, ∬, ∮, ∑, ∏, ∞

#### 关系符
=, ≠, ≡, ≈, ≅, ≃, ∝, <, >, ≤, ≥, ≪, ≫, ∥, ⊥, ∠, △, ∼

#### 集合
∈, ∉, ⊆, ⊇, ⊂, ⊃, ⊈, ⊉, ∪, ∩, ∖, △, ∅, 𝕌, ℕ, ℤ, ℚ, ℝ, ℂ

#### 公式模板
- **结构**: `\frac{}{}`, `\sqrt{}`, `\sqrt[n]{}`, `_{}^{}`
- **大型运算**: `\sum_{i=1}^{n}`, `\int_{a}^{b}`, `\lim_{x \to \infty}`
- **环境**: `\begin{pmatrix}...\end{pmatrix}`, `\begin{cases}...\end{cases}`
- **包裹**: `$...$`（行内公式）, `$$...$$`（独立公式，插入时自动带换行以触发转换）

### 2.3 符号类型

工具栏中的符号分为三种类型：

| 类型 | 说明 | 示例 |
|------|------|------|
| `UnicodeSymbol` | 单个 Unicode 字符，直接插入 | α, ±, ∈ |
| `LatexSnippet` | LaTeX 片段，插入后光标定位到待填位置 | `\frac{}{}` 光标在第一个 `{}` 内 |
| `LatexWrapper` | 包裹选中文字，无选中时插入前后缀并将光标置于中间 | `$...$`, `$$...$$` |

### 2.4 最近使用

- 最多显示 10 个最近使用的符号
- 最多持久化存储 20 个符号
- 使用 SharedPreferences 存储
- 去重机制：重复使用同一符号时移到最前

### 2.5 交互行为

- 点击输入框旁的 Σ 按钮展开/关闭工具栏
- 工具栏展开后点选符号，符号插入到光标位置，工具栏保持打开
- LaTeX 模板插入后光标自动定位到待填位置（如 `\frac{}{}` 光标在第一个 `{}` 内）
- 选中文字后点击包裹类符号，文字被前后缀包裹

### 2.6 代码位置

| 文件 | 说明 |
|------|------|
| `lib/widgets/math_symbols/math_symbols_data.dart` | 符号数据定义 |
| `lib/widgets/math_symbols/math_symbols_toolbar.dart` | 工具栏 UI |
| `lib/widgets/math_symbols/math_symbols_button.dart` | 工具栏按钮 |
| `lib/model/math_symbols_history.dart` | 最近使用符号持久化 |
| `lib/widgets/compose_box.dart` | 工具栏集成 |

## 三、技术实现细节

### 3.1 LaTeX 转换的保护机制

转换过程使用"保护-转换-恢复"模式：

1. **保护阶段**: 将不应转换的区域替换为占位符（`\x00PROTECTED_N\x00`）
2. **转换阶段**: 在剩余文本上应用转换规则，每步转换后保护新产生的 `` ```math `` 块
3. **恢复阶段**: 按逆序将占位符还原为原始内容

这种模式确保代码块和已有数学公式不会被误转换，同时新产生的数学公式块内的 `$` 符号不会被后续规则误处理。

### 3.2 工具栏状态管理

工具栏的显示/隐藏状态由 `ComposeBoxState` 管理：

- `_mathSymbolsToolbarVisible` 状态变量控制工具栏可见性
- `_toggleMathSymbolsToolbar()` 方法切换状态
- 状态通过构造函数参数传递给 `_ComposeBoxBody` 的三个子类
- 切换窄话题（narrow）时重置工具栏状态为隐藏

### 3.3 发送流程

```
用户点击发送
  → 获取消息内容（textNormalized）
  → 检查设置开关是否开启
  → 如果开启，调用 convertLatexDelimitersToZulip()
  → 发送转换后的内容
```

编辑消息时走不同的保存路径，不经过转换逻辑。
