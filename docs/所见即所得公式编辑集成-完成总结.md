## 核心实现

### 输入流程

用户在 compose_box 工具栏点击 📐 按钮：

1. 先检测当前光标是否在 `\(...\)` 公式区域内（`detectLatexAtCursor`）
2. **在公式内**：以现有 LaTeX 作为 `initialLatex` 打开 WYSIWYG 编辑器 → 确认后 `replaceLatexRange` 替换原公式
3. **不在公式内**：打开空编辑器 → 确认后 `insertLatexAtCursor` 在光标处插入 `\(...\)` 包裹的 LaTeX
4. 点击返回 → 编辑器关闭，TextField 内容不变

### 关键 API

| 方法 | 作用 |
|------|------|
| `MathEditorService.openEditor(context, isDark:, initialLatex:)` | 打开 MathLive WYSIWYG 全屏编辑器，返回 LaTeX 或 null |
| `MathEditorService.insertLatexAtCursor(controller, latex)` | 用 `\(...\)` 包裹后插入光标位置 |
| `MathEditorService.detectLatexAtCursor(controller)` | 检测光标是否在公式区域内，返回 `DetectedFormula?` |
| `MathEditorService.replaceLatexRange(controller, range, latex)` | 替换指定范围的公式内容 |

### 界线符处理

- 输入框内存储格式：`\(...\)`（LaTeX inline）
- 发送到 Zulip 服务器前：`lib/model/latex_converter.dart` 的 `convertLatexDelimitersToZulip()` 转换为 `$$...$$`
