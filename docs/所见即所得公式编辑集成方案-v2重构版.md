# 所见即所得公式编辑集成方案 v2（重构版）

> 基于第一次集成的经验，完全重构架构和交互模式。

## 1. 背景

### 1.1 回顾 v1 方案的问题

第一次集成（基于 `flutter_mathlive_mixed` / `mathlive_studio` 包）完成后，暴露出以下问题：

1. **全屏编辑器体验割裂** — `MathLiveEditorPage.open()` 通过 Navigator.push 打开一个独立页面，用户需要在全屏编辑器和聊天输入框之间切换，流程不自然
2. **依赖包环节多余** — 自用项目不需要维护一个通用 Flutter 包，mathlive（TS）→ 包的构建 → zulip-flutter 中间多了一层
3. **包版本滞后** — `mathlive_studio` 使用 MathLive 0.110.0 的官方构建，而本地 mathlive 仓库已有定制修改（如 scrollable-keyboard 布局），难以同步到包中

### 1.2 v2 目标

- **去掉中介包环节**：mathlive（TS 源码）→ 直接 → zulip-flutter
- **交互模式改为内联面板**：像"切换输入法"一样，在输入框下方打开公式编辑区 + 键盘面板
- **使用自定制 mathlive**：基于 commit bba7e54 及后续自定制功能，scrollable-keyboard UI
- **移除遗留功能**：删除 v1 自制数学键盘遗留的 `LatexPreviewArea`（MathLive WYSIWYG 编辑已提供实时渲染）
- **保留原入口图标**：📐 按钮使用原数学键盘图标，位置在「发送」按钮前

## 2. 核心约束（不变，从 v1 继承）

以下约束是 zulip-flutter 与 Zulip 服务器通信的硬性要求，任何方案必须遵守：

1. **输入框内容必须是纯文本**。TextField 中存储的是混合了中文和 LaTeX 语法文本的字符串，例如：`圆的面积是 \(A = \pi r^2\)`
2. **发送到服务器的也是纯文本**。最终提交给 Zulip 服务器的消息内容是纯文本格式，LaTeX 公式以特定界定符包裹
3. **不需要替换 TextField**。WYSIWYG 编辑的结果（LaTeX 代码）以文本形式插入到现有 TextField 的光标位置
4. **渲染使用 flutter_math_fork**。消息历史、预览区域等展示渲染仍使用 `flutter_math_fork`，不做替换

### 详细步骤

1. **输入普通文本**：使用系统键盘在 TextField 中输入中文、英文等普通文本
2. **光标定位**：将光标移动到需要插入公式的位置（或选中要替换的公式）
3. **打开公式面板**：点击「📐 公式」按钮，底部弹出 `MathFormulaPanel`
4. **WYSIWYG 编辑**：在 `math-field` 中可视化编辑公式，下方是自定义虚拟键盘
5. **确认完成**：点击「完成」或点击面板外部，面板收起
6. **LaTeX 自动插入**：编辑器中的 LaTeX 代码（含 `\(` `\)`）自动插入到第 2 步的光标位置
7. **面板可再次打开**：如需编辑或插入更多公式，再次点击「📐 公式」即可

### 与 v1 的关键区别

| 对比项 | v1（全屏弹窗） | v2（内联面板） |
|--------|---------------|---------------|
| 打开方式 | Navigator.push 全屏页面 | 底部面板升起 |
| 编辑区域 | 独立 WebView 页面 | 输入框下方的内联 WebView |
| 关闭方式 | 点击 [Insert] 按钮返回 | 点击 [完成] 或点击面板外部 |
| 编辑完成 | 返回 LaTeX 后手动触发插入 | LaTeX 直接自动填入光标位置 |
| 用户感受 | "打开了一个新页面" | "像切换了个输入法" |

### 4.4 mathlive_editor.html 设计

基于 scrollable-keyboard/index.html 定制：

- 内嵌 `math-field`，不占全屏，高度自适应
- 虚拟键盘使用自定义布局（基本/符号/希腊 三 tab）
- 固定行保留方向键、退格、完成按钮
- 编辑时实时通过 JS Bridge 通知 Flutter 端 LaTeX 变化

## 5. 交互细节

### 5.1 面板打开时机

- 用户点击「📐 公式」按钮 → 面板升起（类似系统键盘）
- 用户双击 TextField 中 `\(...\)` 区域 → 面板升起并加载该公式作为初始值

### 5.2 面板关闭时机

- 用户点击面板上的「完成」按钮 → 面板收起，LaTeX 自动填入光标
- 用户点击面板外部区域 → 面板收起，LaTeX 自动填入光标
- 用户点击「📐 公式」按钮（面板已打开时）→ 面板收起，LaTeX 自动填入光标

### 5.3 面板与系统键盘的关系

- 面板升起时：隐藏系统键盘（抑制 TextField 焦点）
- 面板收起后：恢复系统键盘（恢复 TextField 焦点）
- 行为与旧版自制数学键盘一致

### 5.4 编辑已有公式

双击 TextField 中的 `\(...\)` 区域：
1. 解析出公式 LaTeX 内容（不含界定符）
2. 弹出面板，加载该公式到 math-field
3. 编辑完成后，替换原公式区域

## 6. 与传统数学键盘的关系

旧版自制数学键盘（`math_keyboard/` 目录）已在 v1 集成过程中被移除。MathLive 虚拟键盘完全替代其功能：

| 功能 | 旧自制键盘 | MathLive 虚拟键盘 |
|------|-----------|-----------------|
| 符号分类 | 常用/关系/函数/希腊/模板/最近 | 自定义 tab：基本/符号/希腊 |
| 长按变体 | 自定义实现 | 内置 variant panel |
| 插入方式 | 插入 LaTeX 代码 | WYSIWYG + 键盘按钮 |
| 维护 | 需要维护 | 由 mathlive 上游管理 |

## 9. 实施步骤

### 第一阶段：文件重组

1. 将 `packages/mathlive_studio/lib/` 搬到 `lib/mathlive/`
   - 重命名 `mathlive_studio.dart` → `mathlive.dart`
   - 更新内部 import 路径
2. 将 `packages/mathlive_studio/assets/mathlive/` 搬到 `assets/mathlive/`
3. 删除 `packages/mathlive_studio/` 目录
4. 更新主 `pubspec.yaml`：
   - 移除 `path: packages/mathlive_studio` 依赖
   - 添加 `assets/mathlive/` 声明
5. 更新 `math_editor_service.dart` 的 import 路径
6. 验证编译通过

### 第二阶段：交互重构

1. 基于 scrollable-keyboard/index.html 替换 `mathlive_editor.html`
   - 去除全屏样式
   - 嵌入自定义虚拟键盘布局（基本/符号/希腊）
   - 添加「完成」按钮
2. 改造 `MathLiveEmbeddedEditor` → `MathFormulaPanel`
   - 移除固定高度约束，自适应内容
   - 添加面板升起动画
   - 添加系统键盘抑制/恢复逻辑
3. 改造 compose_box：
   - 📐 按钮不再触发 Navigator.push
   - 改为控制 `MathFormulaPanel` 的显示/隐藏
4. 更新 `mathlive.min.js` 为本地定制构建版本

### 第三阶段：打磨

1. 面板高度与系统键盘一致
2. 面板打开时输入框滚动到合适位置
3. 双击公式进入编辑模式
4. 性能：预加载 WebView 实例
